# Dataset & dashboard sharing notice

The workbook `data/Case.xlsx` was provided as an HR attrition case-study input. It contains 1,000 employee-coded records (IDs such as `EMP0001`) and feature/target columns, without employee names or contact details in the visible fields. **The source, copyright status, and permission to publicly redistribute the workbook have not been independently verified.**

Before making this repository public, confirm that you are permitted to share **both** the case dataset and the Power BI `.pbix` file (Power BI files can contain an embedded data model). If the materials are confidential, remove `data/Case.xlsx` and `dashboard/employee_attrition_dashboard.pbix` from the ZIP/repository and add instructions for requesting or supplying authorized example data. Removing the workbook alone is not enough if the PBIX still embeds it.

The project is a case-study demonstration, **not** a production-ready HR decisioning system. Correlations and group-level resignation shares do not establish causes of resignation. Any use involving real employees would require consent/privacy review, discrimination/fairness review, calibration and validation, human oversight, and organizational policy checks.
